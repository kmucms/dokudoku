- Files are articles. 
- Folders are chapters.
- Filename is first header. 
- Foldername is chapter header.
- Foldernames and filenames can have prefix with number and underscore. 
    This is for ordering filenames/headers in the index. 
    "0" should be used as number-prefix, so all numbers have same length.
- Ordering is based only on nameprefix. It is not grouped by files or folders.
- File extension ".md" is not displayed.
